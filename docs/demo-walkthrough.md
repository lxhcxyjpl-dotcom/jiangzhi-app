# 无 Key 浏览器体验（约 5 分钟）

在浏览器中打开 `app/index.html`。建议使用隐私窗口，避免体验数据覆盖个人浏览器中的任务和记录。全程不需要 DeepSeek Key，也不依赖 `loadDemo`。输入内容请用虚构示例。

## 1. 新建阶段任务（约 1 分钟）

在「今天」页点「＋ 新建阶段任务」，在「最近在推进什么？」中输入 `演示：整理读书笔记`，点「创建」。

**预期：** 今天页出现这个阶段任务。

## 2. 写一个执行点（约 1 分钟）

点「＋ 手动写执行点」。在弹窗中选择刚才的新任务；执行点输入 `打开演示笔记，补上第一条摘要`；完成标准可填 `写完一条摘要`；检查分钟数保留默认值即可。点「保存执行点」。

**预期：** 今天页的任务卡下出现执行点和开始按钮。

## 3. 开始专注，再提前结束（约 1 分钟）

点该执行点旁的「▶ 开始这一段」。专注界面会显示任务和执行点、计时与提示语。无需等待计时结束，点「结束这一段」。

**预期：** 打开「结束三问」流程。提前结束时会多问提前结束原因。

## 4. 回答问题并标记证据（约 1–2 分钟）

逐页回答「有没有出现使原计划失效的新信息？」和「这一段，真实发生了什么？」；在进展里写一句具体发生了什么（例如 `写完第一条摘要`）。提前结束原因选一项。到最后一页，会看到「这个执行点完成了吗？」——默认按进展和提前结束原因填好，可改；然后勾选「✦ 把这次存为进步证据」，点「保存这次专注」。

**预期：** 填了具体进展并勾选证据时，提示已保存并带证据标记。若进展留空仍勾证据，会话会保存，但不会存为证据，并提示「未填写具体进展，未存为证据」。

## 5. 查看记录与回顾（约 1 分钟）

点顶部「记录」，可见刚保存的专注记录。再点记录旁的空心星标也可标记/取消证据。然后点顶部「回顾」。

**预期：** 回顾页展示证据星空和统计；新建记录会进入回顾数据。AI 周回顾按钮需要 Key，本次体验无需点击。
